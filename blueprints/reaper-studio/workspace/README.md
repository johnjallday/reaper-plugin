# REAPER Studio

This workspace holds a catalog of the resources your REAPER setup already has:
project and track templates, Lua, EEL and Python scripts, and the effects and
instruments REAPER reports. It is not a song and has no project file.

The catalog is filled only when you review and approve its sources from the
Studio page and start an inspection. Nothing in REAPER is changed by reading
it, and being listed does not mean a plugin is licensed, loaded or tested.
